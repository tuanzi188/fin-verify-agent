# 查证路由判据与当前实施范围

版本：finance-routing-v2。此次只完成枚举规则、正式路径接入及合成证据回归测试。按用户要求，暂停抽取和标注 20–30 条真实问题，不建立新金标集，也不报告新准确率。

## 一、明确操作判据

| 规则 | 正例 | 反例 | 路径 |
|---|---|---|---|
| 自行计算、验算、换算、差额、排序 | 用两年收入自行计算同比；折合多少亿元 | 年报披露的同比是多少 | Agent |
| 核对、勾稽、解释差异 | 两份文件披露是否一致 | 同一表里的收入与归母净利润分别是多少 | Agent |
| 多公司口径对齐 | 两家公司收入比较 | 单公司两个问号 | Agent |
| 读取披露值 | 披露的毛利率、同比、占比是多少 | 明确要求重新计算 | 先结构检索 |
| 关键条件缺失 | 未指定报告期；净利润口径不明确 | 公司、报告期、归母口径已明确 | 澄清 |
| 主体或期间越界 | 无对应公司文档、超出最新覆盖年度 | 检索空但主体期间在库 | 材料不足 |

多个问号、多个指标、两个年度、同比或毛利率字样，均不单独触发 Agent。多期披露值可以先检索，是否找齐交给证据层判断。

## 二、一次检索证据充分清单

| 条件 | 正例 | 反例 |
|---|---|---|
| 指标明确命中 | 收入问题命中营业收入行 | 命中净利润行 |
| 期间明确命中 | 2025 问题命中 2025 列 | 文档为 2025 年报，但目标列为 2024 |
| 请求字段全部覆盖 | 收入与同比都有相应单元格 | 只有收入原值，缺披露增减幅度 |
| 单位可确认 | 单元格或表格明确千元、百分比 | 裸数字，没有单位 |
| 候选一致且口径可确认 | 相同口径的候选值一致 | 同主体、指标及期间出现不同候选值或单位 |
| 不滥用预览 | 只检查目标行列 | 用周边预览中的其他格子顶替目标 |

返回值为 true / false / null。null 表示规则不覆盖，例如未知指标或长文本语义；不是通过，也不因为规则不认识就自动升级。此层只能检查有限字段，不认证金融语义。当前主体/季度边界仍使用已有 query_scope，其对缺季报场景偏保守，不能声称已充分支持年报中的所有季度披露。

## 三、升级白名单

| 编码 | 具体问题 | 可修复示例 | 不应升级的反例 |
|---|---|---|---|
| retrieval_empty | 在库范围内一次检索为空 | 换查询或进一步读章节 | 公司未入库 |
| metric_missing / period_missing | 某指标或期间证据缺失 | 继续读已定位表格 | 用户根本未明确期间 |
| unit_missing / scope_ambiguous | 单位或口径缺失 | 读表头、标题或附注 | 无材料可供进一步读取 |
| candidate_conflict | 候选冲突 | 核对主表、附注、调整口径 | 用 Agent 随机选择其中一个 |
| numeric_mismatch | 结论与引用数字不符 | 重新读取并核对单元格 | 同一模型接口持续不可用 |
| citation_missing / input_source_missing | 引用或计算输入未完整定位 | 读取原始值并重新绑定 | 未定义的校验类型 |
| requires_calculation | 实际需要计算 | 工具计算并绑定输入 | 披露值只是恰好带百分号 |

error、clarified、语料越界与未知 issue 不自动升级。规则只看结构化 code，reason 原文保留；不通过中文文案反向猜 issue 类型。

## 四、持久化与成本

一次结构检索证据明显不足时跳过该臂的生成；保留证据检查结果。自动升级最多一次，Agent 不再递归升级。中间结果不写历史，最终交付结果只写一次；累计结构 RAG 与 Agent 的模型 token、调用数和执行时长，并保留升级原因。

## 五、暂缓项目

真实问题抽样、人工 initial_path / evidence_sufficient / upgrade_should_happen 金标、证据快照及逐层准确率均暂缓。已有评测文件不改题面和金标；既有通用指标测试中同时修正“某类别完全未命中时 F1 应为 0”的统计边界。无真实金标，不据单元测试宣称正确率提升。
